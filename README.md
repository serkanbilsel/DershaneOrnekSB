# DershaneOrnekSB

An example **course center management application** built with ASP.NET Core MVC.

## 🛠️ Technologies

* ASP.NET Core MVC
* C#
* Entity Framework Core
* SQL Server
* Razor Views
* HTML / CSS / JavaScript

## 📌 Project

A web-based application designed to demonstrate basic management and data operations for a course center.

The project includes:

* Admin panel
* Entity and Model structures
* Entity Framework Core
* Database Migrations
* Controller / View architecture
* CRUD operations
* Static web assets

## 🎯 Purpose

This project was created to practice building web applications with **ASP.NET Core MVC and Entity Framework Core**, focusing on application structure, data access, and standard CRUD operations.
